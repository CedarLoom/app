# CedarLoom app

[![Sponsor](https://img.shields.io/badge/Sponsor-eikelandin-db61a2?logo=githubsponsors&logoColor=white)](https://github.com/sponsors/eikelandin)
[![Checks](https://github.com/CedarLoom/app/actions/workflows/checks.yml/badge.svg?branch=main)](https://github.com/CedarLoom/app/actions/workflows/checks.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue)](REUSE.toml)

The CedarLoom app designs, checks and writes the workflow definitions of a project for the CedarLoom Claude Code plugins, through a command line and a local web UI. Every change is shown as a plan before it is applied and can be undone.

Install and commands: [cedarloom.github.io/app](https://cedarloom.github.io/app/). Development: [AGENTS.md](AGENTS.md) lists the commands and rules. Licenses: [REUSE.toml](REUSE.toml).
