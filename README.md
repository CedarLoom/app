# CedarLoom app

[![Sponsor](https://img.shields.io/badge/Sponsor-eikelandin-db61a2?logo=githubsponsors&logoColor=white)](https://github.com/sponsors/eikelandin)

The CedarLoom app designs, checks and writes the workflow definitions of a project for the CedarLoom Claude Code plugins, through a command line and a local web UI. Every change is shown as a plan before it is applied and can be undone.

Development: [AGENTS.md](AGENTS.md) lists the commands and rules. Licenses: [REUSE.toml](REUSE.toml).
